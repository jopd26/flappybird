# Flappy Bird GitHub Page

This is a simple Flappy Bird-style game built for GitHub Pages.

## How to use

1. Create a new GitHub repository named `your-username.github.io`.
2. Copy these files into the repository root.
3. Commit and push.
4. Visit `https://your-username.github.io` to see the game.

## Files

- `index.html` — page markup
- `style.css` — page styling
- `script.js` — game logic

## Controls

- Click the canvas or press `Space` to flap.
- Avoid the pipes and try to score as many points as possible.
